### About me

I'm a QA Tester working remotely for a US-based company since March 2026. I automate end-to-end tests for ERP systems using AI-powered test automation tools, and I validate scenarios against the real application with **Playwright**. I also test APIs with **Postman** and check data with **SQL**.

I hold a degree in Systems Analysis and Development (IBMR) and a technical degree in IT (ETERJ). I speak fluent English and Portuguese.

### What I do

- Design and automate end-to-end test cases for complex business flows
- Validate scenarios step by step in the browser with Playwright
- Test REST APIs and check responses with Postman
- Query databases with SQL to confirm test data and results
- Report bugs with clear steps to reproduce, expected and actual results
